# Northstar E2E 测试场景用例

## 1. 说明

- 本文基于最新导入流程：仪表盘 → 导入页（/import） → 选择文件 → 覆盖导入（默认）
- 覆盖规则：`data_year + data_month + credit_code + industry_type`
- 导入不清空未出现在 Excel 中的业务数据（保留缺失行）

## 2. 预置条件

1. 后端服务可访问（E2E 默认端口 20260）
2. 前端可访问（E2E 脚本自动启动）
3. 输入 Excel：`prd/12月月报（预估）_补全企业名称社会代码_20260129.xlsx`

## 3. 场景用例

### 场景 A：进入导入页提示选择文件（空状态）

- 前置：系统无导入记录
- 步骤：
  1) 打开首页（仪表盘）
  2) 点击「导入」进入导入页
- 期望：
  - 页面顶部提示「选择文件」
  - 文件名显示「暂无导入记录」
  - 识别结果为 0 Sheet

### 场景 B：覆盖导入（默认）

- 前置：导入页已打开
- 步骤：
  1) 选择输入 Excel
  2) 点击「开始导入」
  3) 等待提示「导入完成」
- 期望：
  - 进度与阶段提示有更新
  - 左侧原始预览出现 Sheet 列表与预览表格
  - 右侧业务映射可展示字段映射（按业务表 → 时间类型 → 字段名）

### 场景 C：覆盖同义记录，不删除缺失记录

- 前置：已有历史数据（同年月）
- 步骤：
  1) 使用 Excel A 导入（包含企业 X）
  2) 使用 Excel B 导入（包含企业 X，且该企业字段变更；不包含企业 Y）
- 期望：
  - 企业 X 被覆盖更新（按主键）
  - 企业 Y 保留不被删除

### 场景 D：导入完成后回到仪表盘

- 前置：导入完成
- 步骤：
  1) 返回仪表盘
  2) 切换到「批发/零售/住宿/餐饮」Tab
- 期望：
  - Tab 企业行数与输入 Excel 行数一致
  - 表格无空白/加载中异常
