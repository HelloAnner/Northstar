# 调整规则

1. 限上社零额月值不低于 0
2. 限上社零额累计值不低于 0
3. 社零总额累计值不低于 0
4. 限上社零额月增速不低于 -30%，不高于 50%
5. 限上社零额累计增速不低于 -30%，不高于 50%
6. 吃穿用月增速不低于 -30%，不高于 50%
7. 小微企业月增速不低于 -30%，不高于 50%
8. 批发业月增速不低于 -30%，不高于 50%
9. 批发业累计增速不低于 -30%，不高于 50%
10. 零售业月增速不低于 -30%，不高于 50%
11. 零售业累计增速不低于 -30%，不高于 50%
12. 住宿业月增速不低于 -30%，不高于 50%
13. 住宿业累计增速不低于 -30%，不高于 50%
14. 餐饮业月增速不低于 -30%，不高于 50%
15. 餐饮业累计增速不低于 -30%，不高于 50%
16. 社零总额累计增速不低于 -30%，不高于 50%
17. 调整限上社零额累计增速后，社零总额累计增速不得低于限上增速 2 个百分点以内
