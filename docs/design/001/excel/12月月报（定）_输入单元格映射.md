# 12月月报（定）输入单元格映射

说明：以下为导出时需要“由代码计算并写入”的单元格位置与计算逻辑（按 sheet 划分）。公式单元格由 Excel 自行计算，不应被代码覆盖。

## 批零总表 / 批发 / 零售

行定位：按模板列 C 行业代码匹配，行内企业顺序按 RowNo/ID 稳定排序。

列映射（每一行）：
- A：统一社会信用代码 = `r.CreditCode`
- B：单位名称 = `r.Name`
- C：行业代码（模板固定，不写）
- D：销售额本月 = `round(r.SalesCurrentMonth)`
- E：销售额上年同期 = `round(r.SalesLastYearMonth)`
- F：销售额当月增速(%) = `ratePercent(D, E)`
- G：销售额本年累计 = `round(r.SalesCurrentCumulative)`
- H：销售额上年同期累计 = `round(r.SalesLastYearCumulative)`
- I：销售额累计增速(%) = `ratePercent(G, H)`
- J：零售额本月 = `round(r.RetailCurrentMonth)`
- K：零售额上年同期 = `round(r.RetailLastYearMonth)`
- L：零售额当月增速(%) = `ratePercent(J, K)`
- M：零售额本年累计 = `round(r.RetailCurrentCumulative)`
- N：零售额上年同期累计 = `round(r.RetailLastYearCumulative)`
- O：零售额累计增速(%) = `ratePercent(M, N)`
- P：首次上报 IP = `r.FirstReportIP`
- Q：最后填报 IP = `r.FillIP`
